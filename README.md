# ProjectTaskManager

Clean Architecture solution in .NET.

## Projects Structure

- **`src/Domain`**: Entidades del dominio y enums.
- **`src/Application`**: Casos de uso, DTOs y reglas de negocio.
- **`src/Infrastructure`**: Acceso a datos, DbContext y repositorios.
- **`src/API`**: Controladores, configuración de OpenAPI y capa de presentación.
